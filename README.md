
## Modelagem de dados com Power BI - Galaxy Schema
Código:

Objetivo: Transformar dados desestruturados de Excel em um modelo dimensional analítico no Power BI.

Descrição: Construção de um Galaxy Schema a partir de múltiplas tabelas desestruturadas, envolvendo a exploração, transformação e modelagem dos dados. O modelo integra diferentes processos de negócio, como vendas, estoque, campanhas e pedidos, por meio de múltiplas tabelas fato e dimensões conformadas, formando uma estrutura analítica centralizada no Power BI.

Habilidades: Data Modeling, Galaxy Schema, DAX, Power Query, RLS, Data Validation

Tecnologias: Power BI, Power Query, DAX, Excel

Resultados: Modelo semântico dimensional integrado, validado e preparado para análises multidimensionais, com Row-Level Security para controle de acesso aos dados.
